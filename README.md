# 📱 GenZpedia

GenZpedia is a gamified mobile application built using React Native and Expo that helps users learn, understand, and practice Gen Z slang, internet culture, emojis, abbreviations, and online communication styles in an interactive and engaging way.

The app combines learning, quizzes, trending slang updates, leaderboards, streak systems, and fun challenges to create an enjoyable learning experience for users who want to stay updated with modern internet language and digital culture.

---

# ✨ Features

## 📖 Slang Dictionary
- Search and explore Gen Z slang words
- Understand meanings, tone, and usage
- Learn abbreviations and internet expressions

## 📈 Trending Slangs
- View currently trending slang terms
- Discover newly added expressions
- Stay updated with internet culture

## 🧠 Interactive Quizzes
- Multiple-choice slang quizzes
- Guess-the-meaning challenges
- Timed quiz rounds
- XP rewards for correct answers

- # 🌍 Crowdsourced Learning Platform

GenZpedia is designed as a crowdsourced slang learning platform where users can contribute and share modern Gen Z slang, internet expressions, abbreviations, and emoji meanings with the community.

Users are not only learners but also contributors who help expand the platform’s slang database with real-world internet language and trends.

## 👥 Community Contributions

Users can:
- Add new slang words
- Submit meanings and explanations
- Share usage examples
- Contribute trending internet phrases
- Suggest emoji interpretations
- Help keep slang data updated

## 📈 Dynamic & Real-Time Content

Since internet slang evolves rapidly, the crowdsourced approach helps GenZpedia stay:
- Up-to-date
- Community-driven
- Trend-aware
- Continuously expanding

## 🎯 Benefits of Crowdsourcing

- Faster slang updates
- Diverse internet culture representation
- Real-world language usage
- Interactive learning environment
- Community engagement

## 🔒 Moderation & Quality Control

To maintain content quality:
- Submitted slang can be reviewed or filtered
- Duplicate or inappropriate entries can be removed
- Trending slang can be prioritized based on popularity

- Learn how slang changes depending on tone and context
